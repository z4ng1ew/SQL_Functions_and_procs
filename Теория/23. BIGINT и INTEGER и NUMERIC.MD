## Три числовых типа PostgreSQL

### INTEGER

Целое число. Занимает 4 байта. Диапазон: от -2 147 483 648 до 2 147 483 647 (примерно ±2.1 миллиарда).

```sql
SELECT 42::INTEGER;         -- ОК
SELECT 2147483647::INTEGER; -- ОК (максимум)
SELECT 2147483648::INTEGER; -- ОШИБКА: переполнение
SELECT 3.14::INTEGER;       -- Результат: 3 (дробная часть отрезается)
```

Аналог в Си: `int` (32-битный).

### BIGINT

Большое целое число. Занимает 8 байт. Диапазон: от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 (примерно ±9.2 квинтиллиона).

```sql
SELECT 42::BIGINT;                    -- ОК
SELECT 9223372036854775807::BIGINT;   -- ОК (максимум)
SELECT 3.14::BIGINT;                  -- Результат: 3 (дробная часть отрезается)
```

Аналог в Си: `long long` (64-битный).

### NUMERIC

Число с произвольной точностью. Хранит **и целую, и дробную** часть без потери точности. Размер зависит от значения.

```sql
SELECT 3.14159265358979::NUMERIC;     -- ОК, все цифры сохранены
SELECT 0.1 + 0.2::NUMERIC;           -- 0.3 (точно!)
SELECT 0.1 + 0.2::FLOAT;             -- 0.30000000000000004 (неточно!)
```

Аналог в Си: нет прямого аналога. Ближе всего — библиотека для работы с большими числами. `float`/`double` **теряют** точность, NUMERIC — нет.

### Сравнение

| Свойство | INTEGER | BIGINT | NUMERIC |
|---|---|---|---|
| Размер | 4 байта | 8 байт | Переменный |
| Дробные числа | Нет | Нет | Да |
| Макс. значение | ~2.1 млрд | ~9.2 квинтиллиона | Практически без ограничений |
| Скорость | Быстрый | Быстрый | Медленный |
| Точность | Точный (целые) | Точный (целые) | Точный (любые) |

### Когда что использовать

```sql
-- INTEGER: обычные счётчики, id, возраст
age INTEGER          -- возраст 22 — хватит

-- BIGINT: большие числа, id с автоинкрементом в больших системах
row_id BIGINT        -- числа Фибоначчи быстро растут

-- NUMERIC: деньги, финансы, точные вычисления
price NUMERIC(10,2)  -- 99999999.99 — цена с копейками без округления
```

`NUMERIC(10,2)` означает: всего 10 цифр, из них 2 после запятой. Это называется precision (точность) и scale (масштаб).
