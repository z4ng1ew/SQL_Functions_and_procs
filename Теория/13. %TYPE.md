## `person.id%TYPE`

Это **не форматирование строки**. `%TYPE` — это специальная конструкция PostgreSQL, которая читается как одно целое: «дай мне тип данных этого столбца».

### Разбор по частям

```
person.id  %TYPE
─────────  ─────
    │        │
    │        └─ «дай тип данных» (ключевое слово)
    │
    └─ столбец id в таблице person
```

`%TYPE` — это **не оператор процента** и **не форматирование**. Это просто синтаксис PostgreSQL, унаследованный от Oracle PL/SQL (процедурный язык базы данных Oracle). Процент здесь — часть ключевого слова, как `#include` в Си — решётка не означает «комментарий», а является частью директивы.

### Что делает

```sql
-- Вместо того чтобы писать тип явно:
id BIGINT

-- Пишем:
id person.id%TYPE
-- PostgreSQL сам смотрит: «какой тип у столбца person.id? BIGINT. Значит id будет BIGINT.»
```

### Аналогия на Си

Ближайший аналог — `typeof` из GCC (расширение GNU для языка Си, позволяющее получить тип переменной):

```c
int x = 42;
typeof(x) y = 10;  // y будет int, потому что x — int
```

```sql
-- person.id имеет тип BIGINT
id person.id%TYPE   -- id будет BIGINT, потому что person.id — BIGINT
```

### Зачем нужен

Если завтра тип `person.id` изменят с `BIGINT` на `INTEGER`:

```sql
-- С %TYPE: функция подстроится АВТОМАТИЧЕСКИ, ничего менять не нужно.
id person.id%TYPE   -- был BIGINT, стал INTEGER — всё само обновилось

-- Без %TYPE: нужно ВРУЧНУЮ найти и исправить:
id BIGINT           -- ← ошибка! person.id уже INTEGER, а тут всё ещё BIGINT
```

### Почему без пробела

`%TYPE` пишется слитно с процентом, потому что это **одно ключевое слово**, а не два. Так же как `#include` в Си пишется с решёткой слитно. Это просто синтаксическое правило PostgreSQL.
