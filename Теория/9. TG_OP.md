## TG_OP

Расшифровка: **T**ri**G**ger **OP**eration — операция триггера.

### Что это

Специальная переменная, которую PostgreSQL **сам заполняет** при каждом срабатывании триггера. Ты **не можешь** в неё ничего положить — она доступна только для чтения.

### Что содержит

Строку с названием операции, которая вызвала триггер. Всего три возможных значения:

```
'INSERT'  — если триггер сработал из-за INSERT
'UPDATE'  — если триггер сработал из-за UPDATE
'DELETE'  — если триггер сработал из-за DELETE
```

Всё. Других значений быть не может.

### Где доступна

**Только** внутри триггерной функции (той, что `RETURNS TRIGGER`). Попытка использовать `TG_OP` в обычной функции или в простом SQL-запросе вызовет ошибку.

### Остальные специальные переменные триггеров

`TG_OP` — не единственная. PostgreSQL заполняет целый набор:

| Переменная | Тип | Что содержит |
|---|---|---|
| `TG_OP` | text | Операция: `'INSERT'`, `'UPDATE'`, `'DELETE'` |
| `TG_NAME` | name | Имя триггера (например, `'trg_person_audit'`) |
| `TG_TABLE_NAME` | name | Имя таблицы (например, `'person'`) |
| `TG_TABLE_SCHEMA` | name | Имя схемы (schema — пространство имён, обычно `'public'`) |
| `TG_WHEN` | text | Когда сработал: `'BEFORE'` или `'AFTER'` |
| `TG_LEVEL` | text | Уровень: `'ROW'` или `'STATEMENT'` |
| `TG_NARGS` | integer | Количество аргументов, переданных триггеру |
| `TG_ARGV` | text[] | Массив аргументов триггера |
| `NEW` | record | Новая строка (INSERT/UPDATE) |
| `OLD` | record | Старая строка (UPDATE/DELETE) |

Все они заполняются PostgreSQL автоматически. Все доступны только для чтения (кроме `NEW` — в BEFORE-триггере можно менять значения в `NEW`, чтобы изменить данные перед вставкой/обновлением).

### Аналогия на Си

Это похоже на `argc` и `argv` в `main()` — ты их не создаёшь, система передаёт их тебе сама:

```c
int main(int argc, char *argv[]) {
    // argc и argv заполнены системой, ты просто читаешь
}
```

```sql
CREATE FUNCTION my_trigger() RETURNS TRIGGER AS $$
BEGIN
    -- TG_OP заполнен PostgreSQL, ты просто читаешь
    IF (TG_OP = 'INSERT') THEN ...
END;
$$ LANGUAGE plpgsql;
```
