## NEW

`NEW` — это **псевдозапись** (pseudo-record), содержащая строку данных **после** операции.

### Простыми словами

Когда ты делаешь:

```sql
INSERT INTO person(id, name, age, gender, address)
VALUES (10, 'Damir', 22, 'male', 'Irkutsk');
```

PostgreSQL создаёт `NEW` — временную «копию» этой строки, доступную внутри триггерной функции:

```
NEW.id      = 10
NEW.name    = 'Damir'
NEW.age     = 22
NEW.gender  = 'male'
NEW.address = 'Irkutsk'
```

Это как структура (struct) в Си, поля которой — столбцы таблицы:

```c
// Аналогия на Си:
struct person {
    int id;
    char name[100];
    int age;
    char gender[10];
    char address[100];
};

struct person NEW = {10, "Damir", 22, "male", "Irkutsk"};
// Обращение: NEW.id, NEW.name, NEW.age ...
```

### NEW и OLD — кто когда доступен

| Операция | NEW (после) | OLD (до) |
|---|---|---|
| INSERT | Есть (новая строка) | Нет (строки до вставки не было) |
| UPDATE | Есть (строка после изменения) | Есть (строка до изменения) |
| DELETE | Нет (строка удалена) | Есть (строка до удаления) |

### Пример с UPDATE

```sql
-- В person: id=10, name='Damir'
UPDATE person SET name = 'Bulat' WHERE id = 10;

-- Внутри триггерной функции:
-- OLD.name = 'Damir'   ← что БЫЛО
-- NEW.name = 'Bulat'   ← что СТАЛО
```

### Где доступны

Только внутри триггерных функций (`RETURNS TRIGGER`), только при `FOR EACH ROW`. При `FOR EACH STATEMENT` — `NEW` и `OLD` **недоступны**, потому что операция затрагивает много строк, и нет одной конкретной строки, на которую можно сослаться.
