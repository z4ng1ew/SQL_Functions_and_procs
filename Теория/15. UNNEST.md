## UNNEST

### Название

`UNNEST` — это **UN** + **NEST**. NEST — гнездо, но в программировании означает «вложенность» (nested loop — вложенный цикл, nested array — вложенный массив). **UN** — приставка отрицания (как «раз-» в русском). Итого: UNNEST = «раз-вложить», то есть **развернуть** вложенную структуру.

### Что делает

Берёт массив и **разворачивает** его в набор строк — по одной строке на каждый элемент:

```
Массив:  [10.0, -1.0, 5.0, 4.4]

         ↓ UNNEST ↓

Строки:  10.0
         -1.0
          5.0
          4.4
```

Аналогия: у тебя коробка (массив) с четырьмя мячами. UNNEST — ты высыпаешь мячи на стол, и каждый лежит отдельно.

### Почему массив в скобках

`UNNEST(arr)` — это вызов функции. `arr` — массив, который мы передаём. Так же как `MIN(price)` принимает набор чисел, `UNNEST(arr)` принимает массив.

### Зачем это нужно

SQL работает со **строками таблиц**, а не с массивами. Функция `MIN()` не умеет принимать массив напрямую. Поэтому сначала разворачиваем массив в строки через UNNEST, а потом применяем MIN:

```sql
SELECT MIN(val) FROM UNNEST(ARRAY[10.0, -1.0, 5.0, 4.4]) AS nums(val);
-- Шаг 1: UNNEST превращает массив в 4 строки
-- Шаг 2: MIN находит минимум среди этих строк
-- Результат: -1.0
```

## `AS nums(val)` vs `AS val`

Это **алиасы** (псевдонимы) для результата UNNEST.

**`UNNEST(arr) AS nums(val)`** — даёт два имени:

```
nums — имя «виртуальной таблицы» (набора строк)
val  — имя столбца в этой таблице
```

```
Таблица "nums":
┌───────┐
│  val  │
├───────┤
│ 10.0  │
│ -1.0  │
│  5.0  │
│  4.4  │
└───────┘
```

**`UNNEST(arr) AS val`** — даёт **одно** имя, которое является и именем таблицы, и именем столбца одновременно:

```
Таблица "val":
┌───────┐
│  val  │
├───────┤
│ 10.0  │
│ -1.0  │
│  5.0  │
│  4.4  │
└───────┘
```

Результат **одинаковый**. Твой вариант `AS nums(val)` — более явный: отдельно имя таблицы, отдельно имя столбца. Вариант однокурсника `AS val` — короче.
