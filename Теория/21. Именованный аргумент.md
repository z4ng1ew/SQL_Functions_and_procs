## Именованный аргумент, не именованный массив

Я неточно выразился. Правильнее: **именованный аргумент** — это когда ты указываешь **имя параметра** при вызове функции.

### Два способа передать аргумент

```sql
-- Способ 1: по позиции (без имени)
SELECT func_minimum(VARIADIC ARRAY[10.0, -1.0, 5.0, 4.4]);
-- PostgreSQL сам понимает: первый аргумент → первый параметр (arr)

-- Способ 2: по имени (именованный аргумент)
SELECT func_minimum(VARIADIC arr => ARRAY[10.0, -1.0, 5.0, 4.4]);
--                          ^^^
--                     имя параметра из определения функции
```

`arr =>` говорит: «передай это значение именно в параметр `arr`». Результат одинаковый, но именованный вызов **читабельнее**, особенно когда параметров несколько:

```sql
-- По позиции — нужно помнить порядок:
SELECT fnc_person_visits_and_eats_on_date('Anna', 1300, '2022-01-01');

-- По имени — сразу понятно что есть что:
SELECT fnc_person_visits_and_eats_on_date(
    pperson := 'Anna',
    pprice := 1300,
    pdate := '2022-01-01'
);
```

### `=>` и `:=` — одно и то же

```sql
arr => ARRAY[10.0, -1.0, 5.0]    -- новый синтаксис (PostgreSQL 9.5+)
arr := ARRAY[10.0, -1.0, 5.0]    -- старый синтаксис
-- Оба работают. Разницы нет.
```
