## Долларное квотирование (`$$`)

`$$` — это **ограничители строки**, а не аналог фигурных скобок. Чтобы понять, зачем они нужны, начнём с проблемы.

### Проблема

В SQL строки оборачиваются в одинарные кавычки:

```sql
SELECT 'hello world';
```

Тело функции — это тоже **строка**, которую PostgreSQL сохраняет в свой каталог. Значит, его тоже надо обернуть в кавычки:

```sql
CREATE FUNCTION ... AS '
BEGIN
    INSERT INTO person_audit(...) VALUES (...);
    RETURN NULL;
END;
' LANGUAGE plpgsql;
```

Но что если внутри тела функции **тоже есть строки с кавычками**? Например:

```sql
CREATE FUNCTION ... AS '
BEGIN
    IF type = 'I' THEN   -- ← тут PostgreSQL запутается:
                          --   где конец тела функции, а где буква I?
    ...
END;
' LANGUAGE plpgsql;
```

Пришлось бы экранировать каждую внутреннюю кавычку удвоением (`''`), что быстро превращает код в нечитаемую кашу.

### Решение — долларное квотирование

`$$` — это альтернативный способ обрамления строк, внутри которого обычные кавычки **не нужно экранировать**:

```sql
CREATE FUNCTION ... AS $$
BEGIN
    IF type = 'I' THEN   -- ← теперь всё нормально,
                          --   'I' не конфликтует с $$
    ...
END;
$$ LANGUAGE plpgsql;
```

Можно добавить метку между долларами для ещё большей ясности — `$BODY$`, `$FUNC$`, `$MY_TAG$` — всё это одно и то же, просто именованные варианты:

```sql
$BODY$ ... $BODY$    -- то же самое что $$ ... $$
$FUNC$ ... $FUNC$    -- то же самое
$ABCDE$ ... $ABCDE$  -- тоже сработает
```

### Аналогия с Си

Ближайший аналог — это не `{}`, а скорее **heredoc** (here document — «документ прямо здесь») из bash-скриптов, который тебе знаком:

```bash
cat <<EOF
Тут любой текст, 'кавычки' не мешают.
EOF
```

```sql
CREATE FUNCTION ... AS $$
Тут тело функции, 'кавычки' не мешают.
$$
```

Принцип одинаковый: задаёшь уникальный маркер начала и конца, а всё между ними — просто текст, без экранирования.

### Итого

| Что | Роль |
|---|---|
| `$$` или `$BODY$` | Ограничители строки (тела функции) |
| `BEGIN ... END;` | Блок кода (аналог `{}` из Си) |
| `CREATE FUNCTION ... AS` | Объявление функции (аналог `int func()` в Си) |
