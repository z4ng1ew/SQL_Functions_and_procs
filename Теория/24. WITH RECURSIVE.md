## Минимальный `WITH RECURSIVE`

```sql
-- Считаем от 1 до 5:
WITH RECURSIVE counter(n) AS (
    SELECT 1              -- базовый случай: начинаем с 1
    UNION ALL
    SELECT n + 1          -- рекурсивный случай: прибавляем 1
    FROM counter          -- ссылаемся САМИ НА СЕБЯ
    WHERE n < 5           -- условие остановки
)
SELECT n FROM counter;
```

Результат:

```
 n
---
 1
 2
 3
 4
 5
```

### Как это работает

```
Шаг 0: SELECT 1           → n = 1   (1 < 5? да)
Шаг 1: SELECT 1 + 1       → n = 2   (2 < 5? да)
Шаг 2: SELECT 2 + 1       → n = 3   (3 < 5? да)
Шаг 3: SELECT 3 + 1       → n = 4   (4 < 5? да)
Шаг 4: SELECT 4 + 1       → n = 5   (5 < 5? нет → СТОП)
```

### Структура — всегда одинаковая

```sql
WITH RECURSIVE имя(столбцы) AS (
    SELECT ...                -- 1) откуда начать (базовый случай)
    UNION ALL
    SELECT ...                -- 2) что делать на каждом шаге
    FROM имя                  -- 3) ссылка на себя
    WHERE ...                 -- 4) когда остановиться
)
SELECT столбцы FROM имя;      -- 5) что вернуть
```

Аналог на Си — цикл `for`:

```c
// То же самое:
for (int n = 1; n <= 5; n++) {
    printf("%d\n", n);
}
```

Только в SQL ты не пишешь цикл — ты описываешь правило, а PostgreSQL сам раскручивает.
