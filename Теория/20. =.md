## `=>` и `:=` в PostgreSQL

Это **не** стрелочные функции из JS. Совсем другое. В PostgreSQL оба символа означают одно и то же: **«передай значение в параметр с таким именем»**.

### Что делают

```sql
-- Оба делают ОДНО И ТО ЖЕ:
arr => ARRAY[10.0, -1.0]     -- «в параметр arr положи этот массив»
arr := ARRAY[10.0, -1.0]     -- «в параметр arr положи этот массив»
```

Разница **только историческая**:

- `:=` — старый синтаксис (работает во всех версиях PostgreSQL)
- `=>` — новый синтаксис (с PostgreSQL 9.5, 2016 год)

### Аналогия

Это как два способа сказать одно и то же по-русски:

```
«Положи в коробку arr вот это»   — :=
«Положи в коробку arr вот это»   — =>
```

Буквально синонимы. Нет никакой разницы в поведении.

### Сравнение с другими языками

| Язык | Символ | Что означает |
|---|---|---|
| JS | `=>` | Стрелочная функция: `(x) => x + 1` |
| PostgreSQL | `=>` | Именованный аргумент: `arr => ARRAY[1,2]` |
| PostgreSQL | `:=` | Именованный аргумент: `arr := ARRAY[1,2]` |
| Си | `=` | Присваивание: `x = 5` |
| PL/pgSQL | `:=` | Присваивание переменной: `x := 5` |

В PostgreSQL `:=` используется в **двух** местах: для присваивания переменных внутри PL/pgSQL-функций и для именованных аргументов при вызове функций. Контекст определяет смысл.

Дело вкуса. В заданиях Школы 21 используют оба варианта. Выбери один и придерживайся для единообразия.
